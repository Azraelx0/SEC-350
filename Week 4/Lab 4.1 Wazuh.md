# Installation of wazuh on xubuntu LTS
- To begin we navigate to the wazuh quickstart guide to find the latest version (for our purposes we run an older version as newer ones won't work on our LTS installation) 
- then run the all in one installation command
  - curl -sO https://packages.wazuh.com/4.3/wazuh-install.sh && sudo bash ./wazuh-install.sh -a -i
    - (-i ignores the reqs so we can install it on the server)
  - wazuh passwords can be found by running:
  - sudo tar -O -xvf wazuh-install-files.tar wazuh-install-files/wazuh-passwords.txt
- Now we can navigate to our mgmt machine and login via browser

## Wazuh/OSSEC Agent on web01
- Find the groups screen in Wazuh, create a new group called linux
- Find the agents screen in Wazuh, Deploy a new agent with the following configuration.
  - Redhat/CentoS
  - CentOS 6 or higher (Note, it will work on Rocky)
  - x86_64
  - 172.16.200.10
  - Linux
  - This will give us syntax for a command that we can run on Web01 to install the agent
  - First, we will install chkconfig on web01
    - sudo dnf install chkconfig
  - Then we run the command generated by wazuh previously
  - Then start the agent on web01 with
    - sudo systemctl daemon-reload
    - sudo systemctl enable wazuh-agent
    - sudo systemctl start wazuh-agent
